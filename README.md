# Codex Academy - Ficha de Treino & Periodização

Aplicativo web progressivo (PWA) e interativo para acompanhamento de fichas de treino, musculação e periodização, com estética retrô (papel vintage/papelão, carimbos e relógio Casio LCD).

## 🚀 Funcionalidades

- **Design Vintage & Imersivo**: Visual inspirado em pranchetas de papelão, clipes metálicos, carimbos clássicos e display LCD esportivo.
- **Acompanhamento de Treinos**: Organização por fichas (A, B, C, etc.), registro de séries, repetições, carga e anotações.
- **Temporizador de Descanso**: Cronômetro integrado estilo relógio LCD para controle do intervalo entre séries.
- **PWA (Progressive Web App)**: Totalmente responsivo para mobile, suporte a instalação e funcionamento offline.

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN)
- **Lucide Icons**
- **Google Fonts** (Courier Prime, Oswald, Caveat, Share Tech Mono)

## 💻 Como Executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno ou hospedar em serviços estáticos como GitHub Pages, Vercel ou Netlify.
